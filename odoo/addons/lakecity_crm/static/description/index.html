Lakecity CRM — Collection Schedule

A clean Odoo CRM module that mirrors the legacy Lakecity Collection Schedule spreadsheet, field-for-field.

Why

Operate the existing collection workflow inside Odoo with zero changes to how staff already think about Stands, deposits, monthly payments, agreements and registration.

Features

  • One CRM record per Stand (chatter, activities, kanban stage board).
  • Every spreadsheet column ported: Stand, customer, deposit, total price, term (12 → 120 mo), monthly payments grid, agreement workflow, registration.
  • Spreadsheet formulas reproduced as stored computed fields: Monthly Payment, Total Paid, Current Balance, Payment Progress, Next Due.
  • Bulk import wizard for the legacy Collection_Schedule_Template_*.xlsx files.
  • Printable PDF report that matches the spreadsheet layout.
  • Pivot view (rows = Stand, cols = month) reproduces the spreadsheet feel.
  • Multi-company aware. User & Manager security groups out of the box.

Business rule preserved

Recurring installments are due on the 5th of every month — enforced by Python constraints on both the schedule's start date and each payment line's due date, exactly as documented in the legacy template.

Designed for Odoo.sh

Ships with a per-module requirements.txt so dependencies (openpyxl) are auto-installed at build time. Manifest version follows the 17.0.x.y.z convention required by the platform.
